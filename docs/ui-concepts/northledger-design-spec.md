# NorthLedger 界面设计规范

## 1. 设计目标

NorthLedger 是资金账户、转账与审计平台，不是“AI 驾驶舱”或科技展示页。界面需要体现银行业务的可信、克制和可追溯，同时让运维人员能快速定位状态和证据。

设计基于本目录四张概念图：登录页、业务门户、交易管理台和移动端。概念图只作为视觉规范，不作为网页背景；所有文字、表格、表单和交互都必须由 React/HTML/CSS 原生实现。

## 2. 核心视觉原则

- 品牌名只使用英文 `NorthLedger`，界面说明使用准确自然的中文。
- 桌面端使用深海军蓝侧栏、纯白主内容、浅灰分隔线；不使用紫粉渐变、3D 球体、玻璃拟态和悬浮卡片堆砌。
- 账户余额是开放式排版带，交易和审计以表格、分栏和抽屉为主。
- 颜色首先表达语义：绿色表示完成，琥珀色表示处理中，红色表示失败或高风险，蓝色表示当前选择和主要操作。
- 动效只用于导航展开、抽屉进入、按钮反馈和页面轻微显现，并尊重 `prefers-reduced-motion`。

## 3. 颜色令牌

| 角色 | 值 | 用途 |
| --- | --- | --- |
| `--navy-950` | `#071426` | 侧栏底色 |
| `--navy-900` | `#0B1E35` | 侧栏悬停/选中底色 |
| `--ink-950` | `#111827` | 主标题、关键金额 |
| `--ink-700` | `#334155` | 正文 |
| `--ink-500` | `#64748B` | 次要说明 |
| `--line-200` | `#E2E8F0` | 表格与分区边界 |
| `--surface-50` | `#F8FAFC` | 页面底色 |
| `--white` | `#FFFFFF` | 主内容面 |
| `--blue-600` | `#1D4ED8` | 主操作、焦点、当前选择 |
| `--green-600` | `#15803D` | 成功 |
| `--amber-600` | `#B45309` | 处理中/注意 |
| `--red-600` | `#B91C1C` | 失败/危险 |

正文和背景对比度不得低于 WCAG AA 4.5:1。状态不能只靠颜色，还要有文字和图标。

## 4. 字体与数字

- 中文正文：`Inter`, `PingFang SC`, `Microsoft YaHei`, sans-serif。
- 英文品牌与数字：`IBM Plex Sans`, `Inter`, sans-serif；不依赖运行时外网字体才能正常显示。
- 页面标题 28-32px / 650，区块标题 16-18px / 650，正文 14px / 1.6，辅助文字 12px。
- 金额、账号、请求编号启用等宽数字；账号与请求编号允许使用等宽字体。

## 5. 布局

- 桌面侧栏固定 232px，主内容最大宽度 1500px，内容内边距 28-36px。
- 顶栏高度 72px，只保留页面标题、环境、用户与必要操作，不放装饰性搜索框或假状态。
- 交易管理页默认“表格 + 右侧详情抽屉”；创建转账使用独立可关闭面板，不挤压浏览主线。
- 900px 以下侧栏变为抽屉；640px 以下使用最多 5 项底部导航，表格以行摘要和详情页代替强行压缩。

## 6. 组件规则

- 按钮最小高度 44px；主要按钮深蓝实底，次要按钮白底描边，危险按钮红色语义。
- 表单必须有可见标签、字段旁错误、提交中状态和成功反馈，不能只使用 placeholder。
- 表格表头浅灰、行高 54-60px、悬停与键盘焦点明确；选中行用浅蓝底和左侧 3px 标识。
- 状态标签使用轻底色、文字和图标，圆角 6px，不使用过度圆润的装饰胶囊。
- 面板只在真实分组需要时使用 10-12px 圆角和极轻阴影；禁止面板中继续嵌套多层卡片。
- 所有图标来自 Lucide，同一界面使用 1.75-2px 描边，图标按钮必须有 `aria-label`。

## 7. 页面结构

### 登录页

左侧深蓝品牌与平台能力说明，右侧白色登录表单。首屏只允许品牌、标题、简短说明、用户名、密码、登录按钮和安全提示，不添加营销指标或 AI 文案。

### 业务总览

先展示总余额与关键业务摘要，再展示账户清单和最近交易。业务指标来自 API，不制造无法解释的假数据。

### 交易管理

以交易表格为主，支持搜索、状态筛选、刷新和发起转账。选中交易后从右侧展示订单、双边流水和平衡校验。

### 审计与用户管理

审计页按时间倒序展示事件、结果、操作者、对象、来源 IP 和 traceId。用户管理只对管理员显示，并且任何响应不得出现密码或密码哈希。

### 系统运行

展示真实 readiness、当前环境/版本和监控入口。外部监控链接必须标明依赖 Compose 观测栈，不能把“链接存在”写成“服务一定可用”。

## 8. 交互与验收

- 支持鼠标、键盘和触摸操作；焦点环始终可见。
- 375、768、1024、1440 四个宽度无页面级横向滚动。
- 加载、空数据、权限不足、网络错误、业务冲突均有不同反馈。
- 登录态只存在服务端 SESSION；前端不把 Token 写入 localStorage。
- 所有非安全方法自动携带 `X-XSRF-TOKEN`，遇到 401 回到登录页，遇到 403 显示权限不足。
